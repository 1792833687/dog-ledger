> 调研日期：2026-10-02
> 配套文档：`docs/compliance/2026-10-02-犬只交易合规要点-法规篇.md`、`docs/compliance/2026-10-02-犬只交易合规要点-平台篇.md`

## 0. 先说清楚这篇文档的边界

**能回答的**：哪些渠道在法律上走得通、哪些在平台规则上被堵死、走每条路之前必须先备齐什么。这部分我有原文依据。

**不能回答的**：你当地谁收狗、什么价、上门还是自提。这不是"我没查到"，而是**这些本来就是本地信息，任何公开检索都拿不到当日实价**。另外要如实说明：本次调研我的联网检索通道在写这篇文档时**被限流了**，后来补查过一轮（见 `2026-10-02-待核实项补查.md`），原计划补充的逐平台规则核实**仍未完成**——淘宝/天猫、京东、拼多多、闲鱼、快手五家逐家尝试过，全部没拿到官方类目规则正文。所以下面凡是标 `［已尝试，未取得官方原文］` 或 `［待你确认］` 的格子，都是**明确没查到**，不是我判断它没问题。

> **证据分级标记见 `2026-10-02-犬只交易合规要点-法规篇.md` §0 的那张表**（本套四份文档共用）。特别提醒：`［查不到］`（规则可能存在但我没取到）与 `［待你确认］`（只有你当地主管部门能回答）是两件不同的事，别混起来读。

## 1. 三条路的状态（结论先行）

| 路径 | 法律层面 | 平台层面 | 现在能不能走 |
|---|---|---|---|
| **抖音小店挂链接卖狗**（平台内成交） | 可行（前提是办出检疫证明） | 《【宠物生活】行业管理规范》类目表：宠物生活 / 宠物活体 / **狗活体 = 暂停招商** | ❌ **新商家进不去**。入驻还要求公司主体、执照含"宠物销售"、线下门店或上游繁育基地的《动物防疫条件合格证》——零散从农户收狗三条资质一条都不满足 |
| **抖音发视频 → 评论区/私信 → 加微信 → 微信成交** | 可行（前提是办出检疫证明） | 《私下交易及导流行为·规则解读》明文禁止：微信号、二维码、电话、"主页加微""私信我"等一切变体；第三方平台白名单只有淘宝/天猫/京东/唯品会/苏宁/考拉/网易严选/洋码头，**微信不在内** | ❌ **不可走**。判罚原文含"永久封禁账号"。这不是"有风险"，是规则写明了要罚 |
| **线下成交**（宠物店 / 犬市 / 大集 / 中间商 / 熟人） | 可行（前提是办出检疫证明 + 运输随货附证明） | 不受电商平台社区规则约束 | ✅ **目前唯一走得通的方向**。但每一单都要能出具检疫证明 |

**一句话总结**：堵死的不是"卖狗"，是"**在抖音上卖狗**"和"**用抖音把人导到微信上卖狗**"。你的生意要落地，销售环节必须发生在**平台之外**，而合规环节必须发生在**卖之前**。

## 2. 所有渠道的共同前置：检疫证明

这一节不重复法条（原文见法规篇），只列**动线**。无论最后走哪条渠道，这一步都躲不掉：

```
收狗（从农户）→ 打狂犬疫苗 → 等免疫生效 → 采血做抗体检测 → 拿到检测报告
    → 提前 3 天向所在地动物卫生监督机构申报检疫
    → 官方兽医临床检查 → 取得《动物检疫合格证明》→ 才能出售/运输
```

三个不能省的硬约束：

1. **提前三天申报** —— 《动物检疫管理办法》第八条第二款。不是当天去当天拿。
2. **犬比猫门槛高** —— 北京 2026 版办事指南：犬需"狂犬病免疫在有效保护期内 **且** 狂犬病免疫抗体检测合格"，材料要"免疫有效保护期内出具的**免疫抗体检测报告原件**"；猫只要一张检疫申报单。
3. **一证多用 = 按最重档罚** —— 《动物检疫管理办法》第四十二条：数量超出证明载明部分、种类/名称/标识号不符、使用转让的证明，**一律按"依法应当检疫而未经检疫"处理**，直接落进《动物防疫法》第九十七条那档：没收违法所得、动物和动物产品 + 同类检疫合格动物货值 **15~30 倍**罚款，货值不足一万的处 **5 万~15 万**，负责人 **5 年禁业**。

> 💡 **这条动线的时间成本，直接决定你的资金周转速度。** 免疫要等生效（法规篇标注的转述是"免疫超过 21 天"，**待确认**），抗体检测要送实验室（几天出报告，**待确认**），申报要提前 3 天。也就是说**一批狗从收到手到能合法卖出，中间有一段只能花钱不能收钱的窗口**。这个窗口有多长、每月能做几批，必须在动第一笔钱之前算清楚——这正是软件「算」页要帮你算的东西。

## 3. 渠道逐条过

每条给出：法律前置 / 其他约束 / 优点 / 缺点 / 要问什么。

### 3.1 本地宠物店、宠物医院（卖断给店主）

| | |
|---|---|
| 法律前置 | 检疫证明随货；运输按《动物检疫管理办法》第四十六条在证明载明目的地、规定时间内到达 |
| 其他约束 | 店主自己也可能被查防疫条件（《动物防疫法》第二十六条）；所以店主会要求你有证明——**有证明的货源反而是你的卖点** |
| 优点 | 一次可出多只；省掉物流与售后；现金结算 |
| 缺点 | 店主压价最狠（他要留自己的毛利）；受店主档期与需求限制 |
| 要问 | 一次能收几只？什么价位？要不要看检疫证明？能不能长期供？ |

### 3.2 犬只交易市场 / 花鸟鱼虫市场（当面成交）

| | |
|---|---|
| 法律前置 | 入场与交易同样要检疫证明 |
| 其他约束 | 《动物防疫法》第二十六条第二款规定"经营动物、动物产品的集贸市场"应当具备防疫条件；第二款之外，**县级以上地方政府可决定在城市特定区域禁止家畜家禽活体交易** —— 但**犬不属于《国家畜禽遗传资源目录》里的畜禽**，这一款的文义**不直接覆盖犬**（法规篇 §2.8）；真正管犬只交易的多是地方性法规，**具体到本市要看本地条例 —— ［待你确认］** |
| 优点 | 直面个人买家，单价通常高于卖给店主 |
| 缺点 | 摊位/时间成本；成交量不确定；**一旦本地地方性法规限缩城区犬只交易，这条路直接消失** |
| 要问 | **本地《养犬管理条例》对犬只买卖、犬类交易市场在城区有什么限制？**（别问「犬算不算家畜家禽」——照《国家畜禽遗传资源目录》，犬不算，见法规篇 §2.8）市场要不要检疫证明？摊位怎么租、多少钱？ |

### 3.3 农村大集 / 集市

| | |
|---|---|
| 法律前置 | 同上，仍要检疫证明 |
| 其他约束 | 农村地区的执法强度通常低于城区，但**"没人管"不等于"合法"**——第九十七条那一档罚则对个人同样适用 |
| 优点 | 门槛最低、几乎无固定成本 |
| 缺点 | 价格低、买家零星、受集期限制 |
| 要问 | 集上卖狗有没有人查证明？ |

### 3.4 狗贩子 / 中间商（上门收）

| | |
|---|---|
| 法律前置 | 你作为出售方仍要申报检疫并提供证明；《动物防疫法》第四十九条的申报义务在**出售人**身上 |
| 其他约束 | 中间商往下游怎么处理是他的事，但**你无法控制**——如果他把狗转手卖给不合规渠道，流转链条上有你的证明记录 |
| 优点 | 最省事，一手交钱一手交货，零物流零售后 |
| 缺点 | 价格最低（他吃掉整条链的利润）；你的检疫成本未必能收回来 |
| 要问 | 收什么犬种/体重？多少钱一斤或一只？要不要证明？ |

> ⚠️ 这条路最容易让人绕开检疫（"反正是他拉走的，我不管"）。**申报义务跟着出售人走**，出了事找的是你。

### 3.5 直接卖给个人（熟人、微信群、本地社群）

| | |
|---|---|
| 法律前置 | 同样要检疫证明。出售即触发第四十九条的申报义务 |
| 其他约束 | 微信个人号在**抖音之外**使用不违反抖音规则（平台篇的导流禁令管的是抖音站内）。但朋友圈卖活体若被举报，仍按《动物防疫法》走 |
| 优点 | 单价最高；可以顺带做口碑、复购 |
| 缺点 | 出货慢、逐个沟通耗时间、要处理"卖出去又退回来"（软件里已有 `returned` 状态和"售后退款"成本项） |
| 要问 | —（这条主要靠你自己经营） |

### 3.6 餐饮 / 肉狗渠道

| | |
|---|---|
| 法律前置 | 同样要检疫证明 |
| 其他约束 | **深圳、珠海等城市已立法禁食猫狗**；2020 年后多地收紧。你所在城市是否允许，**［待你确认］** |
| 优点 | 大批量、去化快、对犬种品相无要求 |
| 缺点 | 单价低；面临伦理与舆情风险；一旦当地禁食就是违法 |
| 要问 | 本市是否禁止食用犬猫？有没有正规的屠宰/加工渠道？ |

### 3.7 繁育基地 / 犬舍（作为他们的供货方）

| | |
|---|---|
| 法律前置 | 他们通常有《动物防疫条件合格证》，**反过来会要求你这一批也有检疫证明** |
| 其他约束 | 平台篇查到：抖音活体类目入驻资质三选一里，有一条是"与上游繁育基地的**购销合同** + 该基地的《动物防疫条件合格证》"。**这意味着：如果你能和一家持证繁育基地建立稳定购销关系，你就有资格去申请那个类目**（前提是类目哪天重新开放招商） |
| 优点 | 出量大、价格稳定、**且是唯一能把你"洗"成平台合规货源的路径** |
| 缺点 | 需要你主动去谈；对方会验你的检疫与免疫记录 |
| 要问 | 收不收外来狗？要不要检疫证明？能不能签长期购销合同？ |

> 💡 **这是全部渠道里唯一带有"战略"性质的一条。** 它同时解决三件事：稳定出货、拿到证明背书、以及未来可能的平台准入。

### 3.8 电商平台（淘宝 / 京东 / 拼多多 / 快手 / 闲鱼）

| | |
|---|---|
| 法律前置 | 一样要检疫证明 |
| 其他约束 | **［已尝试，未取得官方原文］** 淘宝/天猫、京东、拼多多、闲鱼、快手五家本次逐家尝试过，**全部没有拿到官方类目规则正文**（逐家失败点见《待核实项补查》§2.5）。可确认的：抖音（平台篇已查原文）已把猫狗活体从"定向准入"收紧为"暂停招商"，并要求必须用平台备案的有轨迹物流商发货、全面禁止"厂家自送"与无资质快递。其他平台的活体类目普遍也是高门槛高风险类目，**趋势是收紧而非放松**——但这是判断，不是已核实的规则 |
| 优点 | 理论上流量最大 |
| 缺点 | 活体运输死亡责任、售后纠纷、保证金；需要企业主体与仓储能力 |
| 要问 | 每个平台的活体类目是否开放招商？要什么资质？（**逐个去官方规则中心查，别信服务商**） |

> 🚨 **一条必须说的警告**：搜"抖音活体宠物怎么入驻"会出来大量"**报白代办**"广告，宣称还能把你送进活体类目。这些**不是抖音官方渠道**。官方《【宠物生活】行业管理规范》写的是**暂停招商**，且已入驻要求公司主体 + 线下门店或上游基地的《动物防疫条件合格证》。**不要为"报白"付钱。** 你需要核实任何此类承诺时，只认抖音电商学习中心 / 抖店后台的原文。
>
> 第三方观察还提到：抖音在收紧期间半年处置了约 **3993 个违规商家**，并同步上调了保证金与售后责任——`［第三方观察］`，见来源表。

### 3.9 卖不掉的处理（残次、病弱、超期）

- 《动物防疫法》第五十七条第三款：**任何单位和个人不得买卖、加工、随意弃置病死动物**。
- 第九十八条第七项：未按规定处理或随意弃置病死动物 → 3000~3 万元；情节严重停业整顿 + 3 万~10 万元。
- 《动物检疫管理办法》第四十三条：应当检疫而未经检疫、又不具备补检条件的，**予以收缴销毁**。
- → 所以软件里那个"病死犬无害化处理"成本项**不是可选项**。它每只狗都要预留下来，而且要问清当地怎么收、怎么收费（见第 5 节第 5 问）。

## 4. 渠道选择怎么落回软件

这件事的价值不在于换个地方点鼠标，而在于**不同渠道的成本结构完全不同，保本价也完全不同**：

| 渠道 | 特有的成本项 | 对保本价的影响 |
|---|---|---|
| 卖断给宠物店 / 中间商 | 几乎无额外成本 | 保本价 = 沉没成本 ÷ 只数 |
| 自己零售给个人 | 见面油费、退狗风险（`returned` + 售后退款成本项） | 保本价要加上"退回来一只"的期望损失 |
| 犬市 / 大集 | 摊位费、往返油费、守摊人工 | 固定成本按当次只数摊 |
| 平台电商 | 包装、有轨迹物流、死亡赔付、保证金 | 单只成本显著上升 |

设计文档里现在只有一条"批次"，没有"计划去向"。**如果确认要走多条渠道，值得加一个"批次计划去向"字段**，让同一批狗按不同去向分别算保本价——但这属于对已批准设计的改动，**要你点头我才改**。

## 5. 必须由你本地核实的清单（附问法）

打这几通电话比看任何文档都有用。建议直接照着念。

**A. 县/区动物卫生监督机构**（位置、电话、申报点在哪）
1. 出售自己收来的犬，要提前几天申报检疫？具体去哪儿申报？
2. 本地犬产地检疫是不是必须提供狂犬病免疫证明 **和** 抗体检测报告？免疫后间隔多少天才受理？
3. 抗体检测哪家实验室能做？多少钱一只？几天出报告？
4. 检疫证明的有效期是多久？一只一证还是一批一证？运输目的地要写多细？
5. 病死犬无害化处理是强制交给指定单位吗？怎么收费？

**B. 本市农业农村局 / 12345**
6. **本市《养犬管理条例》（或本地地方性法规）对犬只买卖、犬类交易市场、在城区设点卖狗有什么限制？**（原来的问法是「本市城区是否禁止家畜家禽活体交易？犬是否包含在内？」——**这个问法已经过时**：犬不在《国家畜禽遗传资源目录》里，照字面不算「家畜家禽」，该款文义不直接覆盖犬，见法规篇 §2.8。直接问地方性法规更有效。）
7. 本市是否禁止食用犬猫？

**C. 市场监督管理部门**
8. 个人（不注册主体）收购转卖犬只，需不需要办营业执照？有没有备案要求？

**D. 目标渠道方（宠物店 / 犬市管理方 / 中间商 / 繁育基地）**
9. 一次能收几只？什么价？要不要看检疫证明？能不能长期合作？

> 这 9 个问题的答案，决定了软件的「设置」页里那几个默认值该填多少——尤其是每只检疫费和每只病死犬处理费。**在那之前软件里的默认值是 0，算出来的保本价一定偏低。**

## 6. 与「抖音似乎还能入驻」的说法怎么对齐（重要）

本次检索中,我确实拿到了一批看起来"抖音还在招宠物活体"的材料——**这批材料的性质需要说清楚，避免被误导**：

| 材料类型 | 例子 | 真实含义 |
|---|---|---|
| 2026 年 1~2 月的"抓紧最后 X 天入驻"文章 | 多个来源（见来源表） | **是"暂停"生效前的抢跑宣传**，不是当前政策 |
| 各类"报白代办/入驻代办"广告 | 知乎/抖音上的服务商帖 | **服务商营销**，不是官方渠道；官方规范写的是暂停招商 |
| 抖音电商学习中心的官方规范 | 《【宠物生活】行业管理规范》 | **这才是准绳**：狗活体 = 暂停招商 |

时间线（`［第三方观察］`，未逐一取得官方原文）：
