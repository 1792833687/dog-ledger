## 1. 一句话结论

**你想走的两条路，现在同时堵着：**

| 你想做的事 | 平台的态度 |
|---|---|
| 在抖音小店里**合法卖狗** | 类目**「狗活体」目前状态是「暂停招商」**——进不去 |
| 用抖音内容**引流到微信成交** | 平台**明文禁止**的「导流行为」，处罚上限是**永久封禁账号** |

你原定的链路——**抖音发视频 → 评论区/私信 → 加微信 → 微信成交**——落在这两条之间。而这条缝隙**不是合规区**，是**规则里写明禁止的区**。

## 2. 抖音小店卖狗：现状与门槛

［官方原文］抖音电商学习中心《【宠物生活】行业管理规范》（规则中心 → 行业市场 → 行业管理规范）。

### 2.1 现状：狗活体 = 暂停招商 ⚠️

该规范「2.1.2 行业定向准入/定向邀约类目明细」表中：

→ **「狗活体」的状态是「暂停招商」。** 按该规范 2.1.1 对三种入驻方式的定义：普通准入 = 开放招商；**定向准入** = 有额外门槛、可申请；**定向邀约准入** = 仅平台主动邀约。「暂停招商」不属于以上任何一种——**意思是平台目前不接受（新）商家申请开通这个类目。**

**无论你的资质多全，这条路现在是关着的。** 这是本文档里**最需要你优先自行核实**的一条——去后台看「狗活体」类目当前是否可申请。

### 2.2 就算类目开放了，门槛也很高

［官方原文］同一规范「准入要求」表中，宠物生活 / 宠物活体 / 狗活体的**入驻标准**：

1. 店铺类型：官方旗舰店 / 旗舰店 / 专卖店 / 专营店 / **企业店**
2. 营业执照范围
3. 针对纯经营宠物售卖的商家，营业执照的经营范围需要包含「**宠物销售**」
4. 需具备该类目**运输资源及配套退货能力**，提供**店铺主体与运输合作企业的协议证明**，签署《**猫咪 & 狗狗宠物活体品类承诺函模版**》，并加盖开店主体公章

**清出标准**（符合任一即清出）：

1. 近 14 日商家体验分 < 75 分
2. 店铺维度近 30 天存在严重违规处置记录的移除类目权限
3. 商家相关行为已产生负面舆情并对平台或消费者造成了不良影响、商家主体存在其他舆情风险或其他违反承诺函的行为

⚠️ **注意「企业店」起跳。** 狗活体的店铺类型列表里**没有「个体店」**——而同一张表里「水族活体-鱼（特种养殖）」那一行明确写了「或个体店」。

→ **狗活体这条线要求的是公司主体，个体户不行。**

### 2.3 资质要求（原文，狗活体）

［官方原文］该规范「3.1 行业资质和商品资质」表，宠物生活 / 宠物活体 / 狗活体：

**情况一：店铺主体为线下门店**，需提交：

1. 店铺主体的《营业执照》，经营范围含宠物销售
2. 线下门店证明文件，包括 3 个文件：
   - 产权证明或租赁合同，产权证明持有方或租赁合同租赁方需与《营业执照》单位名称一致
   - 含门牌地址的现场实景照片或百度地图截图，地址需与《营业执照》地址一致
   - 含牌匾实体店铺门店实景照片

**情况二：上游繁育基地**，需提交：

1. 与上游繁育基地的**购销合同**
2. 上游繁育基地的《**动物防疫条件合格证**》

**情况三：店铺主体即繁育基地**，需提交：

1. 店铺主体的《营业执照》，经营范围含宠物销售
2. 店铺主体的《动物防疫条件合格证》
3. 场地证明文件，包括 3 个文件（逻辑同情况一，地址需与《动物防疫条件合格证》一致）

**商品资质**（视经营情形）：血统证书（经营宠物猫、狗且宣称血统宠物，需提供宠物协会等行业公认组织颁发的血统证书）；报关单（经营进口商品）；入境货物检验检疫证明（经营进口商品）。

→ **你有三条路满足资质：有实体门店 / 有上游繁育基地的购销合同 + 其合格证 / 自己就是繁育基地。三选一。**

**「从农户零散收狗」不属于其中任何一条**——除非你能拿到与某个繁育基地的购销合同 + 该基地的《动物防疫条件合格证》。

### 2.4 商品页的硬要求（原文）

［官方原文］同一规范「六、商品要求」：

**商品标题**（宠物活体类商品）：

> 【活体】+品种+商品名称+数量+大小（长\宽\重量等）+其他

**商品主图**：png / jpg / jpeg，尺寸至少 600×600，**主图须达到 3 张及以上且必须为实物拍摄图**。

**商品详情**（狗狗、鸟类及用品、仓鼠类及其他小宠、宠物活体需展示）：

- 展示饲养/护理建议，对宠物的保养做详细说明
- 明确售后要求，包括但不限于活体类伤残、疾病、死亡问题，**并在消费者下单后推送**
- 对于狗狗、猫咪活体，**需要增加疫苗信息、驱虫信息透传**
- 需增加购买流程说明
- 需对物流运输流程进行说明
- **需展示「为保障消费者权益，所有成交均在抖音平台进行」提示语**

**推广规范** 7.2.4：

> 在推广宠物活体类商品时，禁止发布易引起用户观看后感到生理或心理不适的内容（如血腥场景、引人不适的动物）。

**售后**：七天无理由；活体类争议按《宠物类商品争议处理细则》处理。

→ **注意最后那条商品详情要求：平台要求你在详情页写明「所有成交均在抖音平台进行」。** 这恰恰是你原计划（成交在微信）的反面。**平台很清楚这类商家想做什么。**

## 3. 站外导流：你原计划的正中心，也是明文红线 ⚠️

［官方原文］巨量百应规则中心《私下交易及导流行为 · 规则解读》。

> **页面迁移提示**：该页顶部载明「自 2020.8.24 起，本网站内容不再维护，内容迁移至『抖音电商大学』」（现为抖音电商学习中心）。即**规则精神延续，但此页面可能不是最新载体**——请自行核对学习中心现行版本。

### 3.1 原文定义

> **私下交易行为定义**：发布含有明确「私下销售」或「绕过平台销售」意图的内容，包括但不限于（**私信我、主页加微、主页有惊喜**等）。
>
> **导流行为定义**：发布站外导流内容，包括但不限于（**微信号、二维码**等）。

**适用范围**（原文）：

> 以下违规情形适用于**口播、直播画面、视频字幕、购物车/视频标题**（以下统称为标题）、**购物车图片**等可向用户传递信息的方式。

### 3.2 明文禁止的行为（原文逐条）

平台禁止发布涉及抖音平台未接入的第三方平台信息，包括但不限于：

- 发布站外导流内容，包含联系方式或以任何形式引导用户私下交易（包括但不限于：**第三方平台水印、平台名 logo、店铺名称、网址链接、qq号（群）、电话、微信号、联系方式（含变体）如「V我」「私信我」「加我」「看个性签名」「主页有微」「主页有惊喜」「微信小程序」「二维码」**等广告信息）；
- **在用户通过商家客服等方式沟通中引导用户进行私下交易的**；
- 以任何直接或间接方式，包括但不限于：通过**第三方平台账户、支付宝、银行卡转账**等引导用户进行线下交易。

**官方 FAQ 原文：**

> **Q：站外导流内容指哪些？**
> **A：** 如**个人微信账号**、商品链接、实体店信息、银行账号及其他付款方式、二维码及其他（非抖音）平台标识等信息。

### 3.3 平台已接入的第三方平台（白名单）

［官方原文］：

> 抖音平台已接入的第三方平台，包含**淘宝、天猫、京东、唯品会、苏宁、考拉、网易严选、洋码头**。

**微信不在其中。** 这是最关键的一句话。

### 3.4 判罚（原文列举，包括但不限于）

- 违规视频仅个人主页可见
- 下架违规购物车
- 账号商品分享功能停用整改 / 永久关闭功能
- 主播违规警告提示
- 直播间商品下架
- 涉嫌违规内容直播中断 / 封禁开播 / 永久封禁直播功能
- **永久封禁账号**
- 依法追究法律责任

［官方原文］《抖音社区自律公约》总则：

> 用户如果违反本公约将面临相应的处罚，处罚类型包括但不限于**删除或屏蔽违规内容、对违规账号禁言或封禁**等；构成违法犯罪的，平台将积极配合执法及司法机关的工作。

### 3.5 一个必须说清的适用性细节（不要据此自我安慰）

上面的《私下交易及导流行为》条款，主体表述是「**达人**在通过购物车分享商品的过程中」——它最直接约束的是**开通了商品分享 / 带货功能的账号**。

如果你的账号**不发商品、不带货，只发内容**，那么平台主要依据《抖音社区自律公约》和《抖音用户服务协议》处理。

**但这不构成安全区：**

1. 《抖音用户服务协议》保留了平台对账号采取**暂停或终止服务**的权利；
2. 《抖音社区自律公约》「九、虚假与不诚信行为」禁止「大量发布、重复上传无特定目标的视频、评论、私信或群聊内容」；
3. ［第三方观察，**非平台官方原文**，可信度低］2024–2025 年抖音、小红书均收紧了对私域导流的管控，实践中「私信/评论区/主页放微信」普遍触发限流、限权、禁言。

**别把「还没被封」当成「不违规」。**

## 4. 把结论摊开说

| 你想做的事 | 平台的态度 | 依据 |
|---|---|---|
| 在抖音小店里卖狗 | **进不去**（狗活体暂停招商）；即使开放也需企业店 + 营业执照含「宠物销售」+ 门店/繁育基地资质 | 《【宠物生活】行业管理规范》 |
| 视频/字幕/口播里引导加微信 | **明文禁止** | 《私下交易及导流行为·规则解读》 |
| 评论区/私信放微信号 | **明文禁止** | 同上 + 《抖音社区自律公约》 |
| 主页留微信、二维码、谐音变体 | **明文禁止**（明确写明「含变体」，含「主页有微」「看个性签名」） | 同上 |
| 客服/私信沟通中引导私下交易 | **明文禁止** | 同上 |
| 让买家扫码 / 支付宝 / 银行卡转账 | **明文禁止** | 同上 |
| 只发内容、不放任何联系方式、成交全在线下 | 不违反上述导流条款 | —— |

### 最诚实的一句

你原定的「**抖音引流 → 加微信 → 微信成交**」，**不是一个「有风险」的做法，是平台写明了要罚、且罚到永久封号的做法。**

另一条「在抖音小店里合规卖狗」的路，类目**目前暂停招商**。

**这两件事都不是我能靠写软件解决的，是要你和合伙人坐下来做的商业决策。** 我能做的是：把它们摆到你面前，别让软件在一个不存在的商业模型上成型。

## 5. 对软件的直接影响

这场调研打掉了软件设计里的**两个隐藏假设**：

### 5.1 引流链路不再成立

「抖音发视频 → 评论区/私信 → 加微信 → 微信成交」曾被写进设计文档，作为「第二期内容归因」功能的前提。

**这条链路现在必须标为「待定」。** 软件将来要记「内容 → 线索 → 成交」的归因，前提是**先有一条合规的链路可供归因**。在此之前，做这套功能是在给一条不存在的路修路标。

### 5.2 成本模型缺两项

法规篇 §5 已说明：**检疫与免疫成本**、**病死犬无害化处理成本**必须能进「算」页面，否则「保本价」是错的。

### 具体怎么改，我不擅自决定

设计文档已获你和伙伴批准，实施计划正在执行（Task 1 已完成）。**改已批准的设计需要你点头。**

我把可选动作列成选项问你，而不是直接改代码。
